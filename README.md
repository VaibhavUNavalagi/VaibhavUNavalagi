## 🧑‍💻 Projects
- 🔹 **[Dump Lexical Extents of Class Definitions (LLVM / Clang)](https://github.com/VaibhavUNavalagi/Dump-Lexical-Extents-of-Class-Definitions-LLVM-Clang-)**  
  Extended Clang/LLVM frontend with a custom flag `-fdump-class-extents` to extract C++ class boundaries for analysis.  

- 🔹 **[AI-Based Efficiency Optimization for DAB DC-DC Converter using TPS Modulation](https://github.com/VaibhavUNavalagi/AI-Based-Efficiency-Optimization-for-DAB-DC-DC-Converter-using-TPS-Modulation)**  
  Applied **Q-Learning** to enhance power control in a Dual Active Bridge converter with TPS modulation. Achieved **99.6% tracking accuracy** and reduced RMS current by **15.2%**.  

- 🔹 **[AI-Powered Video Categorization System](https://github.com/VaibhavUNavalagi/AI-Powered-Video-Categorization-System)**  
  Trained a video categorization model using **Google AutoML & Vertex AI**, achieving high accuracy across **5 activity categories**.  

- 🔹 **[Design and Simulation of a 4-Bit RISC CPU](https://github.com/VaibhavUNavalagi/Design-and-Simulation-of-a-4-Bit-RISC-CPU-Using-Logisim-)**  
  Built a Harvard architecture CPU in Logisim with a custom instruction set and functional ALU, registers, and I/O testing.
